# Hardware Assessment

## Purpose

Capture the hardware available to run the assistant agent, so that model,
runtime, and deployment decisions are grounded in the actual machine rather
than assumptions. This document records what the discovery script finds — CPU,
memory, GPU/accelerator, storage, and OS — and serves as the reference point
for sizing and capability trade-offs made elsewhere in the architecture.
